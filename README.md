# PUC Office Equipment E-Commerce

**Website thương mại điện tử & CRM 3D cho CÔNG TY TNHH THƯƠNG MẠI VÀ DỊCH VỤ PUC**

---

## Tính Năng

- **3D Hero Section (Three.js)** — Mạng hạt 3D tương tác, mouse parallax, showroom nổi 3D chuẩn màu thương hiệu `#0B6EC1`
- **Catalog thiết bị văn phòng** — Máy photocopy, máy in, máy scan, máy hủy tài liệu, máy hút ẩm, mã vạch, vật tư & dịch vụ cho thuê
- **3D Product Viewer 360°** — Xoay 360°, phóng to/thu nhỏ, đổi màu vỏ máy trực tiếp
- **Giỏ hàng & Thanh toán linh hoạt** — LocalStorage `puc_*`, COD và cấu hình VietQR / ngân hàng trong Admin
- **Trợ lý AI Chatbot & Lead CRM** — Tự động bắt SĐT, tư vấn theo ngân sách, đồng bộ vào Admin CRM
- **Admin Dashboard & Analytics** — Quản lý đơn hàng, khách hàng, sản phẩm, thiết bị cho thuê, leads và cài đặt

## Mở Website Trên Máy

```bash
# Chạy bằng script Windows (mặc định cổng 3000)
MO-WEB-PUC.bat

# Hoặc dùng Python / Node HTTP server
python -m http.server 3000
```
